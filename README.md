# Шеф Давид

Личный кулинарный дневник и книга рецептов.

## Запуск
Откройте `index.html` в современном браузере или опубликуйте репозиторий через GitHub Pages.

## Возможности
- Добавление, редактирование и удаление рецептов
- Фото блюда, включая съёмку с камеры телефона
- Оценка вкуса словами: ужасно, плохо, нормально, хорошо, отлично
- Ингредиенты, пошаговое приготовление, заметки на следующий раз
- Категория, дата, время, стоимость, сложность и порции
- Избранное, поиск, сортировка и статистика
- Учёт повторных приготовлений
- Экспорт резервной копии в JSON

## Хранение данных
Рецепты и фотографии хранятся локально в IndexedDB браузера на устройстве. Они не синхронизируются автоматически между устройствами и браузерами. Регулярно используйте «Экспорт данных», чтобы сохранить резервную копию.
